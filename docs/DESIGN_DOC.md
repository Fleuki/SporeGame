# ГРИБНОЙ СУМРАК — ДИЗАЙН-ДОКУМЕНТ

## ЛОР
После падения метеорита мир покрылся гигантскими мутировавшими грибами. Споры в воздухе вызывают галлюцинации и медленно превращают людей в Спороносцев. Под землёй гигантская сеть мицелия соединила всех заражённых в единый разум — Колонию. Герой — выживший исследователь, изучивший грибы и научившийся использовать их химию против них самих.

## ПАЛИТРА
- Трава/фон: #1a3d2e
- Грибы: #6b2d5c
- Токсичные зоны: #c4a000
- Биолюминесценция: #00d4aa
- Кровь/урон: #39ff14
- Доспехи: #5c3a21
- Противогаз: #2a2a2a
- Споры: #8a8a8a

## ВРАГИ
1. Спороносец — бывший крестьянин, голова-гриб. Медленный, облако спор при смерти.
2. Грибной Волк — быстрый, мохнатый, споровый след.
3. Плодовое Тело — ползёт, взрывается ядом при смерти.
4. Мицелиевое Щупальце — вырастает из земли, хватает игрока.
5. Летучая Спора — зигзаг, токсичный след.

## БОССЫ
- Материнская Капля — спавнит миньонов, чихает спорами, оглушается после чиха.
- Мицелиевая Сердцевина — щупальца по всей карте, пульс-ускорение.

## МЕХАНИКА ЗАРАЖЕНИЯ
Под HP есть полоска Спор (0-100%).
- 0-25%: безопасно
- 25-50%: враги +10% скорости, лут ×1.5
- 50-75%: враги +25%, мутации 30%, лут ×2
- 75-100%: враги +50%, мутации 100%, лут ×3, HP -1%/сек

Сброс: антидот-орбы (падают с врагов) или очищенные зоны.

## ПРОКАЧКА (3 карты на выбор)
- Экстракты: скорость, отравление, рикошет, взрыв
- Мутации: +урон/+споры, реген/+споры, +XP/+скорость врагов
- Экипировка: +HP, щит, рывок, авто-лут
