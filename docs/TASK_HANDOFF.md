## ЧЕГО ХОЧЕТ АВТОР

Дословно: «хочу камеру ближе сделать, чтобы игрока было видно, хочу более
атмосферную игру, а не игру за муравья которого не видно, убрать всё лишнее,
убрать волны, убрать количество врагов на поле, расположение HUD сделать более
интересным».

Ключевое: **это осознанный отход от Vampire Survivors.** VS показывает орду с
высоты и делает ставку на количество; здесь хотят обратного — ближе, темнее,
меньше врагов, но каждый читается. Не предлагай отдалить камеру обратно ради
«ощущения орды»: это уже обсуждалось и решение принято.

## ЧТО УЖЕ СДЕЛАНО — НЕ ПЕРЕДЕЛЫВАТЬ

Предыдущая сессия закрыла отдельный пласт работы. Коротко, чтобы не тратить
время на повторный аудит:

- Контактный урон идёт через кадры неуязвимости (`player.iframes`) и
  перезарядку удара у врага (`enemy.touchCd`). Раньше урон шёл каждый кадр.
- Заражение растёт само (`CONFIG.player.sporeGrowth`, % в секунду). Мутации
  крутят `player.sporeRate`, а не глобальный CONFIG.
- У улучшений есть лимит взятий (`max`), одноразовые не выпадают повторно.
- Отдача от попадания: вспышка силуэтом, отбрасывание, цифры урона, криты,
  тряска камеры (`camera.shake`).
- Звук синтезируется через WebAudio в `engine/audio.js`, объект `RECIPES`.
  Файлов нет и не нужно.
- Анимация броска отключена флагом `CONFIG.player.attackAnim: false`; выстрел
  показывают вспышка у ствола (`particles.emitMuzzle`) и свечение снаряда
  (поле `glow` у ствола, хвост рисует `Projectile.draw`).
- Анимация смерти подключена: состояние `dying` в `main.js`, мир на это время
  замирает, крутится только `player.stepDeath()`.
- Тени под существами и притушенные биомы — иначе силуэты тонули в текстуре
  земли.

## ЗАДАЧА 1. Камера ближе

Сейчас зума нет вообще: `Camera` работает один к одному с холстом.

`core/camera.js`:

```js
begin(ctx){ ctx.save(); ctx.translate(-Math.round(this.x+this.ox),-Math.round(this.y+this.oy)); }
```

Нужен множитель. Рабочая схема — **держать `camera.w/h` в МИРОВЫХ единицах**
(`холст / zoom`), тогда вся логика видимости продолжает работать без правок:

```js
begin(ctx){
  ctx.save();
  ctx.scale(this.zoom,this.zoom);
  // округляем в экранных пикселях, иначе пиксель-арт дрожит на дробном зуме
  ctx.translate(-Math.round((this.x+this.ox)*this.zoom)/this.zoom,
                -Math.round((this.y+this.oy)*this.zoom)/this.zoom);
}
```

Стартовое значение — примерно `1.6`, подбирать глазами.

**Что сломается и требует проверки:**

| Место | Почему |
|---|---|
| `Camera.toWorld(sx,sy)` | Мышь приходит в пикселях холста, надо делить на zoom. **Без этого прицел уедет.** |
| `main.js`, `new Camera(...)` | Передавать `screen.width/zoom`, либо считать w/h внутри камеры |
| `CONFIG.waves.spawnMargin` (90) | Видимая область сжимается почти вдвое — враги будут появляться заметно ближе к игроку |
| `CONFIG.world` (4000x3000) | При зуме это уже ~7 экранов. Для «атмосферной» игры арену стоит уменьшить |
| `battleSystem.handleBossEvent`, ветка `summon_tentacle` | Считает точку от `camera.w/h` |
| `mapSystem.visibleProps` / `drawGround` / `drawEdge` | Читают `camera.x/w/h` — при мировых единицах не ломаются, но проверить |

`Renderer.drawVignette`, `drawOverlay`, `drawText` и `input.drawJoystick`
рисуются ПОСЛЕ `camera.end()`, в экранных координатах — их зум не трогает.

## ЗАДАЧА 2. Убрать волны

`systems/waveSystem.js` целиком построен на дискретных волнах: `startWave()`,
`enemiesPerWave`, ожидание зачистки, босс по `wave % bossEvery`.

Заменить на непрерывный спавн с кривой сложности **от времени забега**
(`runTime` уже считается в `main.js`). То есть: враги идут потоком, темп и их
характеристики растут плавно, босс выходит по таймеру.

**Где `wave` торчит наружу — всё это нужно переназначить на время:**

- `main.js` → `HUD.waveDisplay`, `finalWave` в `endGame()`
- `main.js` → `map.drawGround(renderer, waveSystem.wave)`
- `mapSystem.biome(wave)` + `CONFIG.map.wavesPerBiome` — смена биома
- `waveSystem.scale()` — множители HP/урона/скорости врагов
- `waveSystem.pickType()` — какие типы врагов уже доступны
- `index.html` → `<span id="waveDisplay">`, `<span id="finalWave">`

Осторожно с одним: `scale()` сейчас растит HP на 11% за волну. При переводе на
время нужна эквивалентная кривая, иначе сложность либо встанет, либо улетит.
Ориентир — прежний темп примерно одна волна в 40–60 секунд.

## ЗАДАЧА 4. Перекроить HUD

Сейчас всё свалено в левый верхний угол: три подписанные шкалы в столбик плюс
строка статистики. Занимает четверть экрана и выглядит как отладочная панель.

Референс, который прислал автор (Nightfall Survivors): здоровье — ряд сердец
по центру сверху, таймер сверху, полоса опыта — во всю ширину внизу, и больше
на экране нет ничего.

Разумное направление для этой игры (три шкалы вместо двух):

- **Опыт** — тонкая полоса во всю ширину у нижнего края.
- **HP и Споры** — компактной парой у игрока или в углу, без текстовых
  подписей: цвет и иконка уже всё говорят.
- **Таймер** — по центру сверху, крупно. Он же теперь единственная мера
  прогресса вместо волн.

Файлы: `index.html` (разметка), `css/style.css` (`#ui`, `.bar-row`, `.bar-bg`,
`.stats` и медиазапрос), `main.js` → `syncHud()` (объект `HUD`, а также
`hpRow`/`sporeRow` для класса `.critical`).

Текстуры шкал (`bar_frame.png`, `bar_fill_*.png`) уже настроены через
`border-image` и `background-size` от переменной `--bar-w`. **При смене
ширины шкалы `--bar-w` надо менять вместе с `width`** — иначе картинка
заливки обрежется. На этом уже спотыкались в мобильном медиазапросе.

## ЗАДАЧА 5. Атмосфера

Самый расплывчатый пункт, поэтому конкретика — что реально даёт эффект:

- **Свет.** Сейчас арена освещена равномерно. Затемнить всё и оставить
  игроку небольшой круг видимости, плюс свечение от грибных декораций.
  Рисуется одним радиальным градиентом поверх мирового слоя.
- **Меньше врагов, но опаснее.** Прямое следствие ближней камеры: в кадр их
  влезает вдвое меньше, значит каждый должен читаться и что-то значить.
  Снизить темп спавна и поднять характеристики.
- **Тишина между стычками.** Сейчас поток врагов непрерывный. Паузы дают
  контраст, без которого «атмосферно» не бывает.

## КАК ПРОВЕРЯТЬ

Тестов в проекте нет; проверка — запустить и посмотреть.

```
cd docs && python3 -m http.server 8123
```

Chromium предустановлен: `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`,
Playwright ставится через `npm i playwright`. Обязательно вешать
`page.on('pageerror')` — модули ES6 падают молча, в консоли браузера пусто.

Минимум, что нужно прогнать после правок камеры: подвигаться на WASD, повести
мышью по кругу (проверить, что снаряды летят В КУРСОР), дойти до края арены
(камера не должна показать пустоту за границей мира), дожить до смерти.
